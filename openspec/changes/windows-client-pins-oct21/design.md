# Design

## Context

`.config/ci/pipeline.cue` declares `windowsClientPackages`, the exact npm
packages that the GitHub Windows native job installs through
`tools/ci native-clients supply`, and `windowsClientSupplier`, the supplier
archive that the GitLab Windows job extracts from a candidate's public input
package. Both Forge projections are generated from the CUE authority by
`tools/ci project`. Projection tests name the qualified set.

## Goals / Non-Goals

**Goals:** qualify the newest admissible Codex and Claude Code releases on
Windows through the existing native client journey and pin them once.

**Non-Goals:** Mise 2026.10.17, AIGW product code, released artifacts, and
the GitLab public input package, which is built per candidate.

## Decisions

### Pin the Renovate-admitted releases

Codex 0.163.0 and Claude Code 2.1.302 are the newest stable releases past the
three-day minimum release age at the candidate calculation. Claude Code 2.1.303
and later become admissible on later days and follow in a later refresh.

### The CUE authority names the set once

The supplier name is derived from the same versions, and the projections are
regenerated by `tools/ci project`; no version literal is edited in a projection.

### The journey gates forge integration

The lane lands locally first, because the GitHub proposal carries the accepted
head. The GitHub Windows native client journey runs on that proposal with the
new pins and the published predecessor `v0.4.10`. GitHub `dev` and `main` are
published only after it passes; a failure is fixed forward before publication.

## Risks / Trade-offs

- [A client release changes behavior that AIGW's projection relies on] → the
  journey runs the real clients against the published predecessor and the
  candidate before integration.
- [The GitLab journey has no package with the new supplier yet] → each
  candidate's public input package is built for that candidate, so the next one
  carries the new supplier.

## Migration Plan

None; CI selects the new pins on its next Windows client journey.
