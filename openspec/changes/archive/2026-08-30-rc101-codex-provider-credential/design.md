## Decision

Create rc.101 from the exact accepted product shared by local `main`, `dev`,
and `candidate/dev`. `VERSION` remains the release-version authority;
`CHANGELOG.md` remains the user-facing release chronicle.

The release commit is behavior-neutral. After strict specification, source,
native journey, and reproducible artifact proof, create one signed annotated
tag locally and publish the unchanged commit, tag object, and asset matrix to
each selected peer independently.
