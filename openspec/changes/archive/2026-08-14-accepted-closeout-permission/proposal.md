## Why

The controlled Markdown implementation is proved and already integrated into
`candidate/dev`. An earlier ETHOS runtime rejected accepted closeout while
compiling its internal Git effect. The accepted runtime must re-evaluate that
same governed transition without changing product behavior.

## What changes

- bind the current accepted ETHOS runtime to this repository family;
- re-prove the existing product tree under the current lifecycle implementation;
- archive, integrate, close, and retire through ETHOS public commands.

## Out of scope

- direct Git ref mutation or compatibility behavior.
