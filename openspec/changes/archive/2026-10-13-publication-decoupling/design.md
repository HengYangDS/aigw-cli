## Context

An external compiler can have zero runtime coupling while still imposing
source-maintenance and proof burden. AIGW must not install or qualify a drawing
product as a prerequisite for its own convergence.

## Goals and Non-goals

Remove the entire architecture Edition Provider and every live source caller.
Keep native product documentation and generic quality checks. Do not change
source meaning, approved artwork or another contributor's active Lane.

## Decisions

The independent architecture-publications repository owns the authored data,
editorial decisions and drawing checks. It selects pinned source objects
read-only. Replace the mixed Node source gate with its existing native text
test; remove only carrier classes that no longer own tracked source.

## Migration and Recovery

Verify external byte preservation before removing the Provider. Remove its
quality commands, carrier declarations and documentation references in the
same batch. Test the actual quality graph, source architecture policy and
native text check. Git retains original input and accepted deliveries remain
unchanged. Recovery is an exact Git restoration, not a compatibility shim.

## Acceptance and Closeout

Product checks do not invoke or require Publisher. Source-byte preservation,
unchanged source Git state during external execution and accepted delivery
retention qualify removal independently of artwork generation. Successful
public-build qualification belongs to the external publication Change; a failed
render does not become an AIGW prerequisite. Local verification and native
source-owner landing are separate; a work-Lane deletion does not prove
accepted-root convergence.
