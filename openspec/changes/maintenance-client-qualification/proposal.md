# Maintenance Client Qualification

## Why

Published AIGW 0.3.4 passes installed Codex recovery and the three-platform
published-artifact lifecycle, but its final full Windows source check remains
below the existing coverage floor. Its Hermes verifier also creates an empty
home that cannot reuse the healthy official launcher's installed dependencies.

## What Changes

- Exercise public Account inventory and Route recommendation replacement with
  real configuration Stores, preserving unrelated selections and credentials.
- Initialize Hermes verification through the existing official dependency
  selection contract while keeping mutable verification state isolated.
- Reuse that initialization owner in the packaged native-client journey and
  bind its configuration and preservation checks to the actual isolated home.
- Qualify one maintenance successor from signed 0.3.4 source; retain the
  original signed tag, published artifacts, and both failed Windows profiles.

## Capabilities

No specification requirements change. This Change repairs implementation and
acceptance of the existing client-verification and complete-quality contracts.

## Impact

The immutable baseline is signed published commit
`ae9a6b9f7e749256e6cc994338318f59a0d2aca3`. The bounded source scope is
`internal/cli/account/account_test.go`, `internal/cli/route/route_test.go`,
`internal/client/hermes.go`, its native verification variants, existing Hermes,
native-Hermes, and credential-policy tests,
`internal/hermes/configuration`, `tools/release/clients_test.go`, and its
Hermes-specific fixture file.
Release metadata is limited to `VERSION` and
`CHANGELOG.md`. Existing Store, native process, original Hermes launcher,
toolchain, signing, notarization, publication, and Homebrew owners remain in
control. No new dependency, credential backend, process controller, installed
vendor patch, session mutation, or AIGW 0.4 integration is included.

GitLab publication remains independently deferred until intranet access
returns. Preserve operator configuration, model choices, recovery material,
conversation history, foreign work, and current development refs.
