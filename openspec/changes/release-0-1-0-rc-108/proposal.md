## Why

The accepted product now lets a team catalogue remain token-free, presents all
compatible Account credentials as alternatives, and activates compatible
Routes when `aigw sync` observes any available Account. These accepted bytes
are newer than rc.107 and need one immutable release identity.

## What Changes

- Publish the accepted Account connection and synchronization journey as AIGW
  `0.1.0-rc.108`.
- Advance the version authority and release chronicle from the accepted source.
- Publish one signed source and tag object with identical assets to both Forges.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. The behavior is already owned by the accepted `product-control-plane`
and `progressive-team-onboarding` specifications.

## Impact

Only release identity, chronology, and this bounded release Change are
modified. No product behavior, dependency, compatibility path, Proxy coupling,
or Forge-specific implementation is introduced.
