# Terminal quality convergence

## Why

AIGW's accepted tree is functionally verified, but several repository contracts
remain advisory or partial: architecture topology does not yet prove every
product and test package, the ETHOS proof graph is narrower than the product
source gate, material-path coverage is incomplete, and editor/checkout policy
is not closed across platforms.

## Outcome

Close those gaps in the existing owner surfaces. Do not add a second command
plane, compatibility layer, provider abstraction, policy store, or host
assumption. GitLab and GitHub remain independent projections of one local-first
product source.
